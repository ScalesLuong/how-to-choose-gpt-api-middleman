## 十一、cURL 调用 GPT API 示例

```bash
curl https://jeniya.cn/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "system",
        "content": "你是一个专业的中文 AI 助手。"
      },
      {
        "role": "user",
        "content": "如何选择 GPT API中转站？"
      }
    ],
    "temperature": 0.7
  }'
```

其中：

- `model` 表示调用的模型
- `messages` 表示对话内容
- `temperature` 表示输出随机性
- `Authorization` 用于身份验证

具体接口地址和模型名称，需要以平台实际提供的文档为准。

## 十二、Python 调用 GPT API 示例

```python
import requests

url = "https://jeniya.cn/v1/chat/completions"
api_key = "YOUR_API_KEY"

headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {api_key}"
}

payload = {
    "model": "gpt-4o-mini",
    "messages": [
        {
            "role": "system",
            "content": "你是一个专业的中文技术助手。"
        },
        {
            "role": "user",
            "content": "GPT API中转站适合哪些项目？"
        }
    ],
    "temperature": 0.7,
    "max_tokens": 800
}

response = requests.post(
    url,
    headers=headers,
    json=payload,
    timeout=60
)

print(response.status_code)
print(response.json())
```

如果需要提取模型返回的文本，可以使用：

```python
data = response.json()
content = data["choices"][0]["message"]["content"]

print(content)
```

## 十三、使用 OpenAI SDK 接入 GPT API中转站

    model="gpt-4o-mini",

        },
        {
            "role": "user",

## 十六、GPT API 常见错误及处理方式

### 1. 401 Unauthorized

通常表示 API Key 验证失败。

检查：

```bash
Authorization: Bearer YOUR_API_KEY
```

同时确认：

- Key 是否填写正确
- 是否包含 Bearer
- 是否多了空格
- Key 是否过期
- Base URL 是否正确

---

### 2. 400 Bad Request

通常表示请求参数错误。

常见原因：

- JSON 格式错误
- 模型名称错误
- `messages` 结构错误
- 缺少必要字段
- 参数名称拼写错误

建议先使用最小请求进行排查。

---

### 3. 429 Too Many Requests

通常表示请求频率过高或额度不足。

处理方式：

- 降低并发
- 增加重试间隔
- 使用请求队列
- 检查余额
- 对重复请求进行缓存
- 必要时切换模型

---

### 4. 500 Server Error

通常表示服务端异常。

建议：

- 稍后重新请求
- 记录完整错误内容
- 检查平台运行状态
- 增加超时和重试
- 为重要业务设计备用方案
